# OTP Clip

Mac 메뉴바에서 계정을 선택하고 인증하면 OTP가 바로 복사됩니다.

## 다운로드 · 설치 및 사용 안내

**[OTP Clip 다운로드 페이지](https://otp-clip-download.frosty-brook-8851.chatgpt.site)**

다운로드, 설치, QR 계정 등록, 아이콘 선택과 자주 묻는 질문을 한 페이지에서 확인할 수 있습니다.

- macOS 13 이상 · Apple Silicon / Intel 공용
- 계정 클릭 → Touch ID 또는 Mac 암호 인증 → 자동 복사 → ⌘V
- 메뉴바 아이콘 7종 선택
- 문자 인증번호 자동 복사와 카메라·QR 이미지 가져오기

## 자동 업데이트

자동 업데이트 기능이 없는 기존 버전은 1.4 이상을 한 번 직접 설치해주세요. 이후에는 실행 중인 앱이 약 1시간 간격으로 새 버전을 확인하고, 다운로드한 업데이트를 앱 종료·재실행 시 설치합니다. macOS 권한 확인이 필요할 수 있습니다.

[최신 배포 파일과 변경 기록](https://github.com/slowissloth/otp-clip-updates/releases/latest)

이 저장소는 앱 배포와 서명된 자동 업데이트 피드를 제공합니다. 업데이트 전용 비밀키와 실제 OTP 계정 데이터는 포함하지 않습니다.
